# wildcam：苔原延时相机中的稀有动物检测（包括远处的小目标兽群）

**场景：** 固定安装的延时相机俯瞰开阔苔原，按固定间隔拍照，数据量可达数百万张。

**目标：** 找出极少数有动物的图片，例如 270 万张中只有 0.05%。难点在于远处的兽群：只有几个像素，对比度很低，紧贴着地平线。

## 方案

```
同一相机的图片按时间排序
 → 时段背景模型：同一时段（默认每 3 小时一段）最近 12 帧的逐像素中值
 → 光照校正：帧与背景的比值经中值滤波，抵消曝光变化和漂移的云影，保留小目标
 → 稳健 z 分数：|帧 − 背景| ÷ 该像素历史波动（MAD）
 → 地平线条带：由长期中值图估计地平线
     条带内：允许 2 px 的小斑点，相邻斑点合并成"兽群"
     地面：只保留较大的变化（近处动物）；天空：忽略（鸟、云）
 [+ 可选 MegaDetector 分块推理，负责近处清晰可见的动物]
 → 候选确认：冻结 ResNet 提取"当前帧裁剪图 + 背景裁剪图"的特征，加形状统计，用逻辑回归判断
 → 时间支持：相邻帧在合理位移内也出现候选，就加分（10 分钟间隔下目标跟踪器不适用）
 → 每张图打分 → 分流：animal / review / empty
```

### 为什么这样设计

| 常见做法 | 适用性 |
|---|---|
| **MegaDetector + SpeciesNet**（相机陷阱的标准流程） | 近处动物效果好。但官方文档说明它不适合"远处极小的目标"，所以这里只作为可选的近景分支。 |
| **时序背景建模** | 延时相机里减少静态背景误报的主要手段。Jenkins 等（2024）用同时段的 12 张历史图做背景，单帧检测器的 mAP 因此提升 24%。本项目沿用这一思路。 |
| **分块推理（SAHI / MegaDetector tiling）** | 能提高小目标召回，但对只有几个像素、对比度很低的兽群仍然不够，计算量也随分块数线性增长。 |
| **主动学习** | 正样本这么稀少时，最高效的标注方式。见 `review` 命令。 |

## 运行

```bash
pip install -r requirements.txt
python -m wildcam.cli synth  data/synth                         # 2 台相机 × 4 天，分训练集和测试集
python -m wildcam.cli fit    data/synth/train --out models/v1
python -m wildcam.cli run    data/synth/test  --model models/v1 --out runs/v1
python -m wildcam.cli eval   runs/v1 data/synth/test
python -m wildcam.cli review runs/v1 data/synth/test --out to_label/   # 导出最不确定的候选，供人工标注
python -m wildcam.cli eval   runs/v1 data/synth/test --common-with runs/v1_previous --save-as eval_common.json

# 公开数据（LILA，图片从 Google Cloud / AWS 镜像下载）
python -m wildcam.cli cct  data/cct        # Caltech Camera Traps，6 个机位
python -m wildcam.cli duck data/duck       # Duck pictures in wetlands，6 个地点的 10 分钟延时帧
python -m wildcam.cli fit  data/duck/train --mil --config configs/duck.yaml --out models/duck   # 只有图片级标签时用 --mil
python -m pytest -q tests
```

消融实验：加 `--background previous`，就是用"与上一帧相减"代替时段背景模型。

**真实数据的目录结构：** `root/<相机>/<相机>_YYYYmmdd_HHMMSS.jpg`。文件名里没有时间时，读取 EXIF 的 DateTimeOriginal。有标注时放在 `root/<相机>/labels.json`，格式为 `{图片名: [{"kind": "herd"|"near", "box": [x0,y0,x1,y1]}]}`，坐标基于缩放到 `image_size` 后的图片。

## 结果

所有数字都来自本仓库的代码，可用下面的命令复现。"previous"是消融基线：用"与上一帧相减"代替时段背景模型。
median 模式每个时段要先攒够 4 帧才出结果，两种模式参与评测的图片不同，所以下表都用 `eval --common-with` 只在两种模式都有结果的同一批图片上比较。
误报率按"每 1 万张空图中被标记的张数"计算；animal 阈值 0.7，review 阈值 0.3。

### 1. 合成数据（2 台相机，训练、测试各 4 天）

测试集 1088 帧，其中 120 帧有动物（11%）。

| 背景 | AP | review 阈值：召回 / 误报 | animal 阈值：召回 / 误报 | 框召回（兽群 / 近处） |
|---|---|---|---|---|
| 时段中值（默认） | **0.849** | 0.825 / 382 | 0.767 / **72** | 0.804 / 0.778 |
| 上一帧 | 0.806 | 0.942 / 1663 | 0.925 / 599 | 0.931 / 1.000 |

时段背景把 animal 阈值下的误报降到约 1/8，代价是召回从 0.925 降到 0.767。之前的实验里，加光照比中值滤波以前 AP 是 0.559、animal 阈值误报 816/万张；shadow_window 改成 41 后，animal 阈值召回 0.842、误报 248/万张。

合成数据只用来验证流程是否正确，**不代表真实效果**。真实相机还会遇到雾、镜头上的雨雪、热浪扰动、自动曝光跳变和 JPEG 伪影，生成器都没有模拟。

### 2. Caltech Camera Traps（LILA，`python -m wildcam.cli cct data/cct`，配置 `configs/cct.yaml`）

6 个机位（46、43、64、51、18、33），每个机位取 600 张连续时间的图片，前一半训练、后一半测试。评测 1624 帧，其中 1299 帧有动物（80%）。

| 背景 | AP | review 阈值：召回 / 误报 | animal 阈值：召回 / 误报 | 框召回 |
|---|---|---|---|---|
| 时段中值 | 0.859 | 0.684 / 4954 | 0.588 / 3631 | 0.583 |
| 上一帧 | **0.876** | 0.691 / 4862 | 0.627 / 3354 | 0.695 |

在 CCT 上，"与上一帧相减"反而略好。CCT 是触发式相机，连拍的帧间隔约 1 秒，上一帧几乎就是同一时刻的背景；而触发之间的间隔不固定，时段中值的背景常常来自几小时甚至几天前。局限：
- 有动物的图占 80%，不是稀有事件场景，误报率的绝对值意义不大（空图只有 325 张）。
- 近距离的触发式相机，没有远处兽群，地平线模块是关闭的。
- MegaDetector 的训练数据包含 CCT，不能作为公平的基线，所以没有比较。

### 3. Duck pictures in wetlands（LILA，`python -m wildcam.cli duck data/duck`，配置 `configs/duck.yaml`）

芬兰北方森林湿地的固定相机（2025 年），只有图片级标签（没有框）。相机每 10 分钟拍一组（3 张连拍），另有动作触发连拍；`wildcam/duck.py` 按每台相机自己的周期识别出延时拍摄，每组只取第一张，丢掉触发连拍，并裁掉画面底部的时间戳信息条。
6 个地点，每个地点取 864 张连续的延时帧（约 6 天），前一半训练、后一半测试。确认器用 `fit --mil` 从图片级标签做多示例学习。
评测 2424 帧，其中 153 帧有动物（6.3%，152 帧是鸟，1 帧是哺乳动物）。

| 背景 | AP | review 阈值：召回 / 误报 | animal 阈值：召回 / 误报 |
|---|---|---|---|
| 时段中值 | 0.071 | 0.516 / 4654 | 0.373 / 3175 |
| 上一帧 | 0.074 | 0.614 / 5266 | 0.438 / 3470 |

**两种模式都接近随机排序（AP 约等于正样本率 0.063），也就是说，现在的方法在这个数据集上基本无效。** 诊断：
- 有动物的帧和空帧平均都有约 35 个候选，变化检测的信号被水面波纹、反光和风吹的树冠淹没；153 帧有动物的图中有 12 帧没有任何候选。
- 画面里没有天际线，配置关闭了地平线模块，天空不再被忽略，大量候选落在树冠和天空的交界处。
- 很多鸭子在 640×480 下只有几个像素，有的在夜间红外图里肉眼也很难看出。
- 每个地点选的是延时帧里动物最多的一段时间，所以正样本率（6.3%）高于这 6 个目录的整体比例（3.5%），更远高于真实场景的 0.05%。

#### 改动尝试：相机抖动补偿（`background.align`，默认关闭）

用相位相关估计每帧相对背景的平移，把背景平移到当前帧坐标后再做差；平移超过 80 px 的帧跳过。动机是部分相机并不稳定（Lapinjarvi 会转动，中位偏移约 30 px；CCT 6 个地点中 5 个的 95 分位偏移在 57–233 px）。三个固定测试集上、同一批图片的对比（误报为每 1 万张空图）：

| 数据集 | 背景 | AP | review：召回 / 误报 | animal：召回 / 误报 |
|---|---|---|---|---|
| 合成 | 中值 | 0.849 | 0.825 / 382 | 0.767 / 72 |
| 合成 | 中值 + 对齐 | 0.838 | 0.800 / 310 | 0.692 / 83 |
| CCT | 中值 | 0.859 | 0.684 / 4954 | 0.588 / 3631 |
| CCT | 中值 + 对齐 | 0.846 | 0.652 / 4954 | 0.569 / 3939 |
| Duck | 中值 | 0.071 | 0.516 / 4654 | 0.373 / 3175 |
| Duck | 中值 + 对齐 | 0.072 | 0.490 / 4359 | 0.366 / 2853 |

结论：没有改善，AP 在 Duck 上不变、在合成数据和 CCT 上略降，所以保持默认关闭。Duck 的误报不是相机平移造成的，而是水面和树冠本身在变。

### 4. Idaho Camera Traps（LILA，`python -m wildcam.cli idaho data/idaho`，默认配置 `configs/default.yaml`）

美国爱达荷州鱼类与狩猎部的 Reconyx 相机，2016 年 1–4 月，多为开阔的山艾灌丛和积雪山坡，不少机位有天际线，远处的马鹿、鹿、叉角羚很小。276 个地点中有 76 个按 5 分钟间隔延时拍摄，同时也有动作触发拍摄；`wildcam/idaho.py` 只保留落在 5 分钟网格上、且前后 300 秒有相邻帧的延时帧（已用 EXIF 抽查核对），并裁掉上下两条信息条。延时帧各自成一个序列，所以序列级标签就是图片级标签；没有框。
8 个地点，每个地点取动物最多的 1152 张连续延时帧（4 天），前一半训练、后一半测试。确认器用 `fit --mil`。这 8 个地点全部延时帧中有动物的比例为 0.56%，选出的测试集为 13.1%。配置直接用默认配置，没有针对这个数据集调整。

评测 4472 帧（两种背景都已过预热期的帧），其中 587 帧有动物（13.1%）：

| 背景 | AP | review 阈值：召回 / 误报 | animal 阈值：召回 / 误报 |
|---|---|---|---|
| 时段中值 | 0.200 | 0.624 / 3779 | 0.540 / 2976 |
| 上一帧 | 0.338 | 0.540 / 1748 | 0.417 / 1125 |

各机位的 AP（时段中值 / 上一帧）：loc0003 0.18/0.36，loc0012 0.27/0.68，loc0016 0.37/0.60，loc0028 0.09/0.24，loc0036 0.02/0.00（测试段只有 2 帧有动物），loc0044 0.34/0.45，loc0046 0.19/0.27，loc0051 0.27/0.32。

诊断：
- 时段中值在最差的空帧上有 190–400 个候选，铺满整张图。同一时段的背景常常来自前一天或几小时前，期间新雪、积雪融化、夜间红外切换、低角度阳光和阴影让整个画面都变了。上一帧模式用整帧的中位差做归一化，天然抵消了这种整体变化，所以误报少得多。
- 反过来，几乎不动的远处畜群（例如 loc0044 山坡上的马鹿群）在相邻两帧之间几乎没有变化，上一帧模式检不出，时段中值能检出。
- loc0036 测试段只有 2 帧有动物（训练段的远处马鹿群都在前半段），这个机位在测试中基本没有意义。

#### 改动尝试：`background.max_age_hours` 与 `background.global_norm`（默认都关闭）

针对 Idaho 上"时段中值背景过时"的诊断，试了两个开关，参数在看结果前定好：
- `max_age_hours: 2`：背景缓冲只保留 2 小时内的帧，过时的帧丢掉（帧数不够时按预热处理，不出结果）。
- `global_norm: true`：z 分数再除以整帧的鲁棒尺度（中位 z / 0.6745，至少为 1），抵消整体变化。

每个对比都只在两边都出了结果的同一批图片上计算（所以 `max_age_hours` 那几行的图片数少于前面的表）：

| 数据集（图片 / 有动物） | 方法 | AP | review：召回 / 误报 | animal：召回 / 误报 |
|---|---|---|---|---|
| 合成（896 / 98） | 中值 | 0.837 | 0.806 / 313 | 0.755 / 63 |
| | 中值 + max_age | 0.885 | 0.867 / 526 | 0.827 / 63 |
| 合成（1088 / 120） | 中值 | 0.849 | 0.825 / 382 | 0.767 / 72 |
| | 中值 + global_norm | 0.849 | 0.825 / 382 | 0.767 / 83 |
| CCT（790 / 620） | 中值 | 0.866 | 0.615 / 3647 | 0.537 / 2353 |
| | 中值 + max_age | 0.858 | 0.644 / 3941 | 0.582 / 3118 |
| CCT（1624 / 1299） | 中值 | 0.859 | 0.684 / 4954 | 0.588 / 3631 |
| | 中值 + global_norm | 0.852 | 0.650 / 4985 | 0.554 / 3692 |
| Duck（1899 / 128） | 中值 | 0.076 | 0.453 / 4094 | 0.297 / 2688 |
| | 中值 + max_age | 0.079 | 0.352 / 3179 | 0.234 / 1875 |
| | 上一帧 | 0.078 | 0.594 / 5353 | 0.445 / 3450 |
| Duck（2424 / 153） | 中值 + global_norm | 0.073 | 0.497 / 4553 | 0.320 / 3122 |
| Idaho（4037 / 563） | 中值 | 0.228 | 0.615 / 3356 | 0.533 / 2631 |
| | 中值 + max_age | 0.236 | 0.586 / 2867 | 0.499 / 2265 |
| | 上一帧 | 0.360 | 0.551 / 1759 | 0.426 / 1143 |
| Idaho（4472 / 587） | 中值 | 0.200 | 0.624 / 3779 | 0.540 / 2976 |
| | 中值 + global_norm | 0.198 | 0.610 / 3542 | 0.514 / 2844 |

结论：
- `global_norm` 在四个数据集上都没有改善。误报并不是整张图一起变，而是阴影边缘、灌丛、积雪表面等局部在变，整帧的中位数压不住它们。
- `max_age_hours` 在合成数据上 AP 提高 0.048，在 Idaho 和 Duck 上只提高 0.003–0.008，在 CCT 上略降，同时让可评测的帧变少（CCT 从 1624 降到 790）。效果不一致，保持关闭。
- 在 Idaho 上，"上一帧"仍明显优于时段中值的各个变体。原因在于背景过时之外，还有局部的光照和积雪变化。下一步应针对这类局部变化，或者把两种背景结合起来（例如上一帧负责压误报，中值负责找静止的畜群），而不是继续调整中值背景。

## 公开数据调研（2026-11）

没有找到同时满足"固定延时相机 + 苔原远景 + 远处兽群标注"的公开数据集。相近的有：

| 数据集 | 内容 | 差异 |
|---|---|---|
| LILA BC（Snapshot Serengeti、Caltech Camera Traps、ENA24 等） | 大量相机陷阱图片。Serengeti 约 76% 是空图；Caltech 共 24.3 万张、140 个机位 | 多为红外触发、近距离拍摄，没有远景兽群 |
| Marburg Camera Traps（LILA 的"其他数据集"列表） | 约 6 千张，开阔的北极平原 | 物种和标注情况待确认 |
| Duck pictures in wetlands（LILA） | 67.6 万张，芬兰湿地固定相机，10 分钟延时 + 触发连拍，约 98% 是空图 | 只有图片级标签；是森林湿地不是苔原；已接入，见上文 |
| 阿拉斯加北部海岸平原相机（NSF Arctic Data Center） | 40 个站点，触发拍摄加 5 分钟间隔延时（2019、2021–2023 年夏季） | 最接近；标注情况需要查阅 |
| 驯鹿、麝牛的航拍数据（无人机，HerdNet 等） | 从空中俯视拍摄的兽群 | 视角不同 |

当前环境无法访问 arcticdata.io 和 datadryad.org（Penguin Watch），所以暂时没有接入。建议：放行这些域名后，在阿拉斯加北部海岸平原的延时数据上验证；真实部署时，用 `review` 命令做几轮主动学习，积累正样本。
